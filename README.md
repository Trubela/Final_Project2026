# Green Fredericton 

A website that lists eco-friendly local shops in Fredericton.

Made by Joseph Trubela, Pedro Garbelotti and Gustavo Quintal for our Responsive Web Design class.

## Pages
- **Home** – welcome page
- **Shops** – list of the shops
- **About** – what the site is about
- **Contact** – send us a message

## Built with
HTML, CSS, Bulma and JavaScript/jQuery.
